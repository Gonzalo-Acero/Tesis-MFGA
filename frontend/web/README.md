## Estructura de Página 
La idea es usar una combinación de `onescroll` con algunos archivos _.html_ en secciones como _Contacto_ y para agregar un buen frontend al _Registro_
*(Hay que revisar la ubicación de cada uno de los arhivos _[front y back]_ dentro del `MVC`)*

### Javascript
Implementar Javascript para front y backend.
#### Conexion
Implementar backend con `Node.js`, consultar a Ani para usar el mismo framework.

### Estilos 
Implementar `Popper.js` y/o `Bootstrap` para agilizar los estilos con uso de hoja CSS.
#### Imágenes 
La idea es combinar imágenes de sitios reales con high fidelity wireframes de la app.
